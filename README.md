# AgileFlow Playbook

> An open-source, source-grounded Agile and Scrum knowledge playbook designed for AI agents and Agile practitioners.

## About AgileFlow

AgileFlow is a knowledge and reasoning framework for helping users understand and apply Agile and Scrum accurately.

It is designed to help with:

- Agile and Scrum concepts
- Product Backlog management
- Product Backlog Item refinement
- User stories and requirements
- Acceptance criteria
- Sprint Planning
- Sprint Goals and Sprint Backlogs
- Estimation and sizing
- Quality practices and Definition of Done
- Sprint Reviews and Retrospectives
- Inspection and adaptation
- Agile/Scrum troubleshooting
- Academic Agile/Scrum work

A central design principle of AgileFlow is to distinguish **formal Scrum requirements** from commonly used Agile practices, optional techniques, course requirements, and team-specific conventions.

## Why AgileFlow?

Many Agile resources combine Scrum rules, popular practices, project-management habits, and team conventions without clearly distinguishing them.

AgileFlow uses a source hierarchy to reduce this confusion:

1. Scrum Guide 2020 — primary authority for formal Scrum definitions
2. Agile Manifesto and Principles — authority for Agile values and principles
3. Scrum.org — supporting practical explanations
4. Academic/course material — educational context
5. Complementary Agile practices — useful but not automatically required
6. Team conventions — context-specific

## Core Principle

> Do not treat every commonly used Agile practice as an official Scrum requirement.

For example, AgileFlow does not automatically classify the following as mandatory Scrum requirements:

- User stories
- Acceptance criteria
- Definition of Ready
- Story points
- Planning Poker
- Fibonacci estimation
- Velocity
- Burndown charts
- Jira
- Two-week Sprints
- The three Daily Scrum questions
- TDD
- Continuous Integration
- A particular testing framework

These may be useful practices, but their classification depends on the relevant source and context.

## Intended Use

AgileFlow can be used as:

- A knowledge base for AI agents
- A reference for Agile/Scrum learners
- An educational resource
- A starting point for Agile workflow assistants
- A reference for teams adapting Agile practices to their context

AgileFlow does not attempt to prescribe one universal Agile process.
